RISKS AND MITIGATIONS
================================================================

SINGLE-INSTANCE DEPLOYMENT
  Risk: EC2 instance failure takes the app down
  Mitigation: RDS database is separate and survives an instance failure;
  relaunching a new EC2 instance and deploying the JAR restores the app
  in under an hour. The deploy script is included and documented.

API COST VARIABILITY
  Risk: Pipeline API costs can spike if misconfigured
  Mitigation: Pipeline frequency controls are in application.yml;
  Anthropic console has monthly spend caps; cost optimization rules
  are documented in CLAUDE.md. Current spend is ~$200-400/month.

CONTENT QUALITY DEPENDENCY
  Risk: AI-generated content quality depends on upstream API providers
  Mitigation: The pipeline uses multiple providers (Anthropic, Perplexity,
  Alpaca); if one fails, others continue. Prompts are version-controlled
  and tunable via text files — no code changes needed.

SUBSCRIBER EMAIL DELIVERABILITY
  Risk: SES bounce/complaint rates affect deliverability
  Mitigation: SES is in production mode with verified domain. The
  unsubscribe workflow is self-service. Current deliverability is clean.
