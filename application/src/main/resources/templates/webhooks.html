Setup Guides

Slack

  1. Go to your Slack workspace settings
  2. Navigate to Apps → Incoming Webhooks
  3. Create a new webhook for your channel
  4. Copy the webhook URL and paste above

Microsoft Teams

  1. Open the Teams channel you want alerts in
  2. Click … → Connectors → Incoming Webhook
  3. Name the connector and create
  4. Copy the webhook URL and paste above

Custom Endpoint

  1. Set up an HTTPS endpoint that accepts POST
  2. Payloads are JSON with eventType, title, summary
  3. Respond with 2xx to confirm receipt
  4. Paste your endpoint URL above
