Search Filters

Purpose

Search the full article database by title, topic, author, source, or body text. Use this to find specific articles you've seen before, explore what's been harvested from a particular feed, or narrow down articles by date range.

How It Works
  1. Fill in one or more filter fields below — all fields are optional.
  2. Non-empty fields are AND-combined: results must match every filter you specify.
  3. Text fields use case-insensitive substring matching, so partial terms work.
  4. Results are returned with title, source, topic, and publication date for quick scanning.
