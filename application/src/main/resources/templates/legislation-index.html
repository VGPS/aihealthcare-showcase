Enacted U.S. state laws regulating artificial intelligence in healthcare

About This Registry

A curated, source-linked registry of enacted U.S. state laws regulating the use of artificial intelligence in healthcare. Covers payer utilization review restrictions, provider disclosure requirements, claims downcoding protections, mental health AI safeguards, consumer chatbot regulations, and comprehensive state AI acts. Each entry links to official legislative text and secondary analysis sources.

How to use this page
  1. Browse — Scroll the table to see all laws, sorted by year (newest first) then state.
  2. Filter — Use the dropdowns above to narrow by State, Category, or Status. Combine filters for precision (e.g., California + Payer Utilization Review).
  3. Search — Type keywords in the Search box to match across titles, bill numbers, and regulated parties.
  4. Sort — Click the up/down arrows on any column header to re-sort the table.
  5. Details — Click any law title to see the full detail page with key requirements, enforcement, and source links.
  6. Export — Use the "Save as CSV" or "Save as Text" buttons at the bottom to download the current filtered view.
  7. Map view — Logged-in users can access the State Map for a geographic summary, or Upcoming for laws with approaching effective dates.
