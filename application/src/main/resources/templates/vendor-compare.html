* Document Frequency Scoring — Each vendor's relevance score is calculated as the number of retrieved source documents that explicitly mention the vendor divided by the total number of source documents evaluated. For example, a score of 0.40 means that 40% of the retrieved sources reference that vendor by name or product. This approach provides an objective, evidence-based measure of vendor presence in the literature.

* TF-IDF Scoring — Each vendor's relevance score uses Term Frequency-Inverse Document Frequency, a classic information retrieval algorithm. TF (mentions / total sources) measures how frequently a vendor appears. IDF (log(1 + total sources / mentions)) downweights vendors that appear in nearly every document (generic mentions) and upweights vendors concentrated in a subset of highly specific sources. The raw TF-IDF value is normalized so the top-scoring vendor receives 1.0. This approach rewards specificity over raw frequency.
