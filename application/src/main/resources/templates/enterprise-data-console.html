Enterprise Data Console

Submit data jobs, monitor progress, and download artifacts

1. Select a Data Feed — choose what type of data to export (Articles, Market Digest, Regulatory Events, etc.).

2. Add a Prompt (optional) — describe the specific data you want. For AI Synthesis feeds this shapes the analysis. Leave blank to fetch all available records.

3. Choose format and row limit — CSV opens in Excel/Sheets; JSON is for programmatic use. Row limit controls how many records are returned (max 50,000).

4. Click Submit Job — the job runs in the background. When complete, your browser will automatically prompt you to save the file. The job also appears in the Jobs tab for reference.

Artifacts are retained for 14 days. Use the Schedules tab to set up recurring automated exports delivered to your inbox.
